# RALLY 11 — MOTION SPIN

iPhone Safari / PC対応のブラウザ卓球ゲーム。インストール不要。

## 操作
- **指を上下左右に動かす**：ラケットが指の位置に追従します（角度調整ボタンなし）。
- **打ち返す瞬間に上へスワイプ**：トップスピン。
- **打ち返す瞬間に下へスワイプ**：バックスピン。
- **打ち返す瞬間に左右へスワイプ**：横回転。
- 止まって打てばほぼフラット。回転の強さはラケットの移動速度で決まります。
- **サーブ**：プレイヤー側のサーブ時にコートをタップ。
- **PC**：矢印キー / WASDでラケット移動、スペースでサーブ。

ボールがコート外に飛び出すと、カメラが球を滑らかに追尾してから次のポイントへ進みます。
背景は白を基調にした明るいデザイン。11点先取・2点差・3ゲームマッチ。

## 公開済みGitHub Pagesの更新
解凍したフォルダ内の **index.html / sw.js / manifest.webmanifest / アイコン** を既存リポジトリのルートにアップロードし、変更をコミットしてください。
既存URLはそのまま使えます。古い表示が出るときはSafariを再読み込みし、ホーム画面アプリは終了して開き直してください。service workerのキャッシュバージョンはv3に更新済みです。

## 備考
回転・衝突・カメラの挙動は遊びやすいように調整したゲーム向けの簡易モデルで、厳密な卓球物理ではありません。外部ライブラリやネット接続は不要です。
