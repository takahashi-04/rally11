# RALLY 11 — Table Tennis

iPhone / Android / PC のブラウザで遊べる、1ファイル完結の卓球ゲームです。

## 遊び方

1. `index.html` をSafariやChromeで開きます（iPhoneでは下記のGitHub Pagesなど、HTTPS上で公開して開く方法を推奨）。
2. 難易度を選んで「試合をはじめる」。
3. コート上で指を左右にドラッグし、手前のラケットをボールに合わせます。
4. 自分のサーブはコートをタップして開始します。球を打つときの指の動きがコースに影響します。
5. 「ドライブ」と「カット」を切り替えられます。

11点先取、2点差、3ゲームマッチです。PCでは左右矢印キーで移動、スペースキーでサーブ、1/2で球種変更できます。

## iPhoneで遊ぶ手順（GitHub Pages）

- GitHubで新しい公開リポジトリを作成します。
- このフォルダの **中身すべて**（`index.html`、アイコン、`manifest.webmanifest`、`sw.js`）をリポジトリのトップにアップロードしてcommitします。
- GitHubの Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/ (root)` → Save。
- 発行された `https://ユーザー名.github.io/リポジトリ名/` をiPhoneのSafariで開きます。
- Safariの共有メニューから「ホーム画面に追加」を選べます。初回のオンライン起動・キャッシュ完了後は、対応する環境ではオフラインでも起動できます。

公開GitHubリポジトリにアップロードするのはゲームのソースだけにし、個人情報などのファイルは含めないでください。

## 技術・特長

- HTML + CSS + JavaScript、Canvas 2D APIのみ。
- PWA（ホーム画面アイコンとService Workerによる静的ファイルのキャッシュ）に対応。
- npmや外部ライブラリ、サーバー、バックエンド、APIキー、外部画像は不要。
- CPU対戦、3段階の難易度、得点、サーブ交代、11点制、ドライブ/カット、短い効果音、最高ラリー数の端末内保存。
- ゲーム自体にファイル送信などのネットワーク機能はありません。
- この作品は見下ろし気味の疑似3D描画を用いたカジュアルな卓球ゲームです。物理演算・打球判定は遊びやすさ優先の簡略モデルです。
